# Closing map illustrations

The seven drawings use the map's existing ComfyUI model
(`krea2_turbo_int8_convrot.safetensors`) and PencilartD LoRA. The shared art
direction, individual prompts, dimensions and seeds live in `scenes.json`.

Prepare the individual API workflows in `tmp/map-illustrations/` without contacting a server:

```bash
node scripts/image-workflows/map-illustrations/generate.mjs
```

Generate and download the drawings from a running ComfyUI instance:

```bash
node scripts/image-workflows/map-illustrations/generate.mjs --url http://localhost:8188
```

Use `--only potion` (or any other scene name) to regenerate one drawing. The
script queues one image at a time and reports ComfyUI errors. It keeps original
PNGs in the ignored `tmp/map-illustrations/` directory and writes transparent
WebP assets to `site/src/assets/landing/map-illustrations/`. White paper is
removed without losing the coloured pencil marks. Inspect each result before
integrating it; the boat's bow must point up to follow the route's rotation.

For a Windows instance accessible only through Windows loopback from WSL, add
`--curl /mnt/c/Windows/System32/curl.exe` and use the instance's actual port.
Reprocess saved PNGs without generating again with `--process-only`.

Art direction: graphite boat, green/turquoise exploration, ochre treasure, violet woodland alchemy, amber campsite and sapphire ancient relic.

The sea cursor uses `paper-boat.webp`, generated by ComfyUI from the `paper-boat`
entry in `scenes.json` (seed 914425), cropped to a transparent 256 × 192 WebP.
Regenerate just that illustration with `--only paper-boat`. It is loaded lazily
with the map and painted as a raster image; the cursor has no vector boat fallback.
